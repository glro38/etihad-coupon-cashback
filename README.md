## How to enter a promo code on Etihad Airways

The promo code field isn't on the payment page — it's inside the flight search menu, which is why many people miss it.

1. Open the flight booking menu on the Etihad homepage and enter your departure city, destination, and travel dates, then pick Economy, Business, or First.
2. Look for the blue **Promo Code** link in the bottom-left corner of the booking menu.
3. Click it. A new Promo Code field appears above the "Book with miles" switch.
4. Paste your code (copy-paste, don't type it — trailing spaces kill codes), then run the search. The price updates automatically if the code applies.

If the price doesn't move, run through the usual suspects: is the code valid for your cabin class and route? Does it require a logged-in Etihad Guest membership? Is there a minimum fare? Is your travel date inside a listed blackout period? Codes generally must be applied during booking — most can't be retrofitted to an already-issued ticket.

## FAQ

**Can you stack multiple Etihad promo codes?**
Probably not in the same booking. One coupon directory claims codes can usually be combined if terms allow; another explicitly states each order accepts one promotional offer. The one-code-per-booking rule matches how most airline checkout systems behave, so plan on a single discount and treat anything beyond that as a pleasant surprise. Cashback is a separate mechanism and generally operates independently of fare discounts, though it's worth confirming the cashback terms before assuming both will track.

**What's Etihad's refund policy if I change my mind?**
If your departure is more than 7 days away and you cancel within 24 hours of booking, a full refund may be possible. Non-refundable fares can still recover government taxes. Refund timelines run 5–14 business days for card payments, up to 45 days for bank transfers. On changes: you can modify or upgrade up to 2 hours before departure, but changes and cancellations inside 96 hours of the flight can carry a 10% fee, and a fixed $30 charge applies to cancellations, modifications and new bookings. Specific fare rules override these general terms.

**Why does my Etihad promo code keep failing?**
In order of likelihood: the code is expired or capped, your route or cabin isn't covered, there's a minimum fare you haven't met, your travel dates fall in a blackout window, or you need to be logged in as an Etihad Guest member. Try a fresh browser session (or incognito mode) if none of those apply — cached sessions cause phantom failures.
